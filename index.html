贵州村超 · AI 短片创作与投放实验

独立完成约 90 秒 AIGC 全流程短片（角色 / 场景 / 分镜 / 动态视频 / 剪辑），真实发布抖音，并用投放数据诊断开头与节奏问题。

我的工作 · AIGC 制作阶段

  • 独立完成 AIGC 全流程：侗族少女 IP 形象设计 → 剧本 → 分镜脚本（含每镜场景画面提示词）→ AI 生成角色 / 场景 / 动态视频 → 剪辑包装成片
  • 通过提示词工程解决生成不稳定：保证角色一致性、画面衔接与动作表现，完成 88 秒可发布成片
  • 真实投放抖音作为传播实验样本，回收信息流点击与前 3 秒完播数据

我的工作 · 投放与数据诊断阶段

  • Python 采集抖音 / 小红书 / 视频号数据，构建「平台流量 × 内容供给 × 受众需求」三表，量化题材供需差
  • 三角测量：问卷（n=30）+ 真实流量 + 同类对标，提出「双层漏斗」模型定位流失发生在元开头与前 3 秒
  • 针对开头吸引力与叙事节奏，输出标题 / 开场重构方案与 5 条可落地优化建议

关键发现

  • 2 秒跳出率 48.60%（优秀线 2.4 倍）、完播率 2.26%：问题不在内容质量，而在前 3 秒开场与元开头
  • 问卷 100% 正面反馈 vs 真实流量冷启动失败——好素材也要匹配开头钩子与节奏
  • 人文故事 / 美食题材供需差最大，是后续可切入的素材方向；「95 岁侗家奶奶」单条播放 5 亿+ 验证人文叙事价值

北京卫健委 · 「京小医」IP 健康科普 AI 短片

为官方健康传播打造「京小医」IP，完成从剧本文案、分镜到 AI 成片的创意全流程。

我的工作

  • 设计「京小医」IP 形象与人物设定，撰写系列剧本文案与分镜脚本（含每镜场景画面提示词）
  • 用 AI 视频工具完成场景生成与动态化，剪辑包装成可发布的科普短片
  • 搭建「供给—需求—流量」研究，用数据决定拍什么主题最有流量（问卷 + 舆情 + 平台流量校验）
  • 沉淀可复用提示词模板与创作方法论，提升后续产能与画面一致性

关键发现

  • 供需错位：中医保健供给 70.66% 但公众关注仅约 23%（低回报），运动健身 / 起居作息为高潜力机会区
  • 饮食调理是唯一「声量 + 关注」双高主题（关注 84.95% / 流量 78.51%），为绝对核心流量密码
  • 起居作息 ROI 最优（高点赞内容均赞 4,745）；据此确定「饮食 + 运动 + 起居」组合创作方向

康希诺 PCV13 · 社媒聆听与选题研究

为新品上市做用户画像与市场趋势研究，支撑内容选题与营销策略——创意素材背后的洞察依据。

我的工作

  • 构建「用户画像 + 用户决策旅程」四级 / 五级标签体系（基于冰山模型：消费理念 → 育儿理念 → 健康认知 → 自费疫苗接受度）
  • 设计 AI 大模型批量文本标注流程，完成全年 6 平台主贴数据的标签化
  • 使用 SPSS 完成社媒分布、情感、代际 / 周期交叉分析，输出 v6 分析结果
  • 撰写含 75 张数据表的研究报告，并输出全国舆情地域热力图

关键发现

  • 平台「双核驱动」：小红书 46.71% 为口碑主战场，抖音 34.34% 承担广域触达
  • 用户决策旅程呈「沙漏模型」：认知 / 推荐两端高、信息搜集中间低
  • Z 世代妈妈「科学 + 社交」双驱动；新品优佩欣陷入「高认知、低转化、弱口碑」断层，据此提出三阶段内容营销策略
